# Task 2 — Build React App

Self-promotional single page app made with React + Vite.

Live: https://zhangirxan.github.io/js-react/

## Components

`Header`, `Hero`, `About`, `Interests`, `Contacts`, `Footer`

## Run

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Builds the app and pushes `dist` to the `gh-pages` branch.
