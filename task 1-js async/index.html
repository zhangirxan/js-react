      Step-by-step explanation
      1. Call Stack runs the whole script synchronously: A: script start, then asyncDemo() is pushed on the stack and prints B: async start. At await the function is paused and popped off the stack. Then C: script end. The stack is now empty.
      2. While the script ran, callbacks were only scheduled: 3 timers went to the Task Queue (through the Web API timer), .then callbacks and the continuation after await went to the Microtask Queue in the order they were registered.
      3. The Event Loop sees an empty stack and drains all microtasks: D: promise 1, E: promise 2, F: async after await. E returned, so its chained .then is queued at the end → G: promise 2 → then.
      4. Only when the microtask queue is empty does the loop take one task: H: timeout 1. Then I: timeout 2, which queues a microtask.
      5. After every task the microtask queue is drained again, so J: microtask inside timeout 2 runs before K: timeout 3, even though timeout 3 was scheduled long before.
